# Keuanganku

Aplikasi keuangan pribadi versi 1.0.

## Fitur
- Dashboard saldo
- Pemasukan & pengeluaran
- Kategori transaksi
- Edit/hapus transaksi
- Grafik pengeluaran dengan Chart.js
- Filter riwayat
- Dark mode
- Export/import JSON
- Data tersimpan di LocalStorage
- Responsive untuk HP

## Menjalankan
Buka `index.html` di browser.

## Hosting gratis
Bisa di-upload ke GitHub Pages. Tidak membutuhkan PHP/MySQL untuk versi ini.

Catatan: Chart.js dimuat dari CDN, jadi grafik membutuhkan koneksi internet. Fitur pencatatan tetap menggunakan LocalStorage browser.
